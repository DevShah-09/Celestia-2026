# PLAYVERSE Leaderboard

React + Vite recreation of the supplied PLAYVERSE leaderboard reference.

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Notes

- The supplied fantasy artwork is used as `src/assets/images/playverse-background.png`.
- Navbar, search, leaderboard rows, pagination, sidebar and bottom cards are real React/HTML components.
- Team search filters the sample data by team.
- Pagination works across the full sample dataset.
- Floating rocks, crystals and the stone-serpent border have lightweight CSS animation.
- Replace the DiceBear avatar URLs with your own local assets/API when the final character art is available.
